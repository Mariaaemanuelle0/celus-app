# Celus

Espaços e serviços por perto, num mapa. App web instalável (PWA) em React + TypeScript.

## Rodar no computador
1. Instale o Node.js 20 ou mais novo.
2. `npm install`
3. Copie `.env.example` para `.env` (pode deixar vazio para usar dados fictícios).
4. `npm run dev` e abra o endereço que aparecer.

## Estrutura
- `docs/` decisões de produto, pacote original e protótipo aprovado
- `src/` código do app
- `supabase/migrations/` banco de dados
